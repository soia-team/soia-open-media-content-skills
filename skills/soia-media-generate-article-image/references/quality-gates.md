# Article image quality gates

每次生成后按顺序执行，任何一项失败都不能写“测试通过”。

## 1. 产物真实性

- 最终文件是 PNG/JPG/WebP 等真实位图，能读取像素尺寸。
- 本次输出目录包含落盘 Prompt、位图和 manifest。
- 本次正式产物目录不新增 HTML、SVG、canvas 页面或截图脚本。

## 2. 内容来源

- 标题、数字、人物、来源和结论能回指输入文章。
- 没有把 Agent 推测写成原文事实。
- 客户保留的个人观点区没有被代写。
- 最终 Prompt 包含注册表规定的全部 required blocks；缺一项即不进入生图。

## 3. 文字

- 将图上文字与 Prompt 的 `exact_text` 逐项人工核对。
- 中文错字、乱码、缺字、重复字、随机英文均判失败。
- 文字过小无法在目标用途下阅读判失败。
- `plugin_icon` 分两阶段判定：设计稿阶段图上不得有文字（有则重生成）；矢量终稿阶段
  只允许出现模板规定的底部标签，其余文字一律判失败。
- 图标终稿不接受扩散模型直出——实测尺寸、底色 hex 与字形占比均打不准，
  必须由矢量脚本重绘后再验收。

## 4. 构图与比例

- 实际像素比例与目标比例一致或在生图工具的可解释容差内。
- manifest 同时记录 requested 与 actual；生图工具只返回原生比例时必须写明差异，不得把目标比例写成已通过。
- 无裁切、遮挡、重叠、溢出、异常边框或未使用的大块死区。
- 康奈尔模板必须保持左侧问题、右侧笔记、底部回顾；左右栏塌成上下结构判失败。

## 5. 参考图一致性

- 参考图角色已明确；仅参考风格/构图时没有复制其示例内容。
- 对照参考图检查信息密度、留白、配色、手绘/像素/编辑质感。
- 只要结构正确但媒介与质感明显不符，仍判为需重生，而不是“通过”。

## 6. 版本化重生

- 失败后写新 Prompt 和新文件名，不覆盖旧位图。
- 每轮只修一个主要问题，并在 manifest 记录失败项与变化。
- 禁止用任何代码在已生成位图上补字、遮字或重新排版。
