# 视觉机制：字体蒙版（Typographic Mask）

这是一个可叠加到任何使用场景和美学系统的构图机制，不是独立 preset。

## composition_and_layout

- 让一个主题词或地点名成为主视觉字形；字腔内部承载与主题事实相关的影像或材质。
- 字形占画面约 35–55%，保持完整轮廓和可读性；图像只进入字腔或一个受控越界区域。
- 固定基线、外边距、主标题位置和信息锚点；批量系列只改变主题对象、色相、裁切或知识卡位置中的 2–4 项。
- 缩略图阅读顺序：系列栏目/日期 → 巨型主题词 → 主命题 → 3–5 个知识点 → 来源/CTA。

## visual_style_and_materials

- 字体角色使用超大窄体或高反差展示字；正文使用清晰无衬线，中文与拉丁文按视觉灰度校准。
- 字腔内素材用自然光摄影、受控低彩度、纸张印刷或主题材质；背景和结构色由所选美学系统决定。
- 允许一个扰动：细手绘线、圆角信息卡或局部越界；避免装饰堆叠、随机 Logo 和无关小字。

## exact_text

逐页列出系列名、主题词、日期、知识点、来源标记和 CTA。生成模型无法稳定保证高风险文字时，
切换 `hybrid_exact_text`，只校正文字层，不替换已通过的主视觉。

## constraints_and_avoid

- 不把模型标签（例如 GPT2）写入画面，除非用户明确要求展示该标签。
- 不生成虚构城市地标、未经来源支持的今日宜忌、二维码、品牌或英文微文案。
- 不把十页信息压成一张等权信息墙；一页只承担一个主题对象和一组新知识点。
