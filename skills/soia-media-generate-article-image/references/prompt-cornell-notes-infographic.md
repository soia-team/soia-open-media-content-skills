# Prompt template: Cornell Notes infographic

## 适用场景

- `image_type: learning_note`
- 文章学习总结、知识教程、概念说明、方法复盘
- 输出必须是 imagegen 生成的真实位图，不生成 HTML

## 最终 Prompt 母本

```text
Use case: scientific-educational
Asset type: A4 portrait Cornell Notes learning infographic for an article summary

Primary request:
根据【文章正文】设计一张或一组高质量的「康奈尔笔记」信息图，用于学习和复习【文章主题】。内容必须只来自原文，先在内部提炼问题与答案，再把它们画成 1–6 页完整学习资料；不要展示分析过程。

Input images:
【逐张填写参考图角色，例如：Image 1–2 是成品风格与信息密度参考；Image 3 是康奈尔结构说明参考。它们不是编辑目标。】

Canvas and style:
- A4 竖版比例，高清、接近 4K 的精细度
- 手绘教材信息图与清爽 Flat Design 的结合，不是网页截图，不是 PPT，不是 UI
- 暖白纸张背景，低饱和马卡龙蓝、绿、橙、淡黄
- 中文字体清晰，标题略带手写感，正文像优质教材批注
- `visual_base: cornell-dense-study-sheet-v1`：顶部书本/课题/日期栏、左绿右蓝 25%/75% 双栏、底部双总结栏必须保留；这是已认可的高密度母版，不是重新设计
- 模块紧凑但可扫描，细线边框、圆角浅色分区；禁止用大标题和大留白替代知识模块
- 图标、箭头、表格和示意图保持统一的手绘学习资料风格
- 如果提供参考成品，标记为 `style_density_reference`：只继承版式、颜色角色、字体层级、模块密度和材质，不复制参考图事实或文字

Fixed composition — must preserve this spatial relationship:

1. 顶部横向信息栏
- 左侧：书本图标 + 主标题“康奈尔笔记”
- 右侧：日期、科目、课题
- 课题使用【文章主题】；来源信息可以小字号放在页脚，不出现 Logo
- 多页时在左上角安全区固定显示【页码，例如 01/03】；页码不能只放在文件名或页脚，也不能与标题重叠

2. 左侧约 25% 宽度：线索栏（提问）
- 浅绿色底，标题逐字写“线索栏（提问）”
- 单页放置 8–12 个与文章主题相关的问题，编号排列；系列正文页目标 6–10 个，内容不足才减少
- 问题覆盖：中心判断、关键概念、关系/步骤、例子、边界和复习重点
- 每个问题都必须能在右侧笔记栏找到答案

3. 右侧约 75% 宽度：笔记栏（记录）
- 浅蓝色标题条，标题逐字写“笔记栏（记录）”
- 按原文知识点拆成 6–11 个独立模块；单页 8–12 个模块优先，系列每页至少 6 个完整模块（来源不足除外），保持信息密度接近已认可的大学教材总结页
- 每个模块包含：编号、小标题、简洁解释、项目符号
- 原文确有关系时，加入流程图、箭头关系、比较表、示意图或统一图标
- 不要只有文字；但没有数据、流程或对比时不得虚构图表
- 重点词可以用淡黄、淡蓝、淡绿或淡粉色块强调
- 不得把一页做成 3–4 个大卡片、只有阶段标题或大片空白；10 个主题能在单页清晰容纳时不得拆成稀疏三页

4. 底部横向区域
- 左侧大区标题逐字写“总结栏（回顾）”，用 2–5 句话概括全文
- 右侧便签标题逐字写“一句话记忆”，用一句最容易复述但不过度夸大的话总结全文

Content source:
- 文章标题：【逐字标题】
- 文章主题：【主题】
- 文章正文：【完整正文或经确认的 source-grounded 内容底稿】
- 线索问题：【8–12 个逐字问题】
- 笔记模块：【6–11 个模块的逐字标题与关键内容】
- 总结栏：【2–5 句逐字总结】
- 一句话记忆：【逐字句子】
- density_audit：【cue_count】、【note_module_count】、【page_role】、【page_label】；每个问题与模块必须有覆盖关系

Pagination and series contract:
- 先按章节、知识模块、源文字长度和信息密度决定 `page_count`；默认运行 `scripts/resolve_cornell_pagination.py`，结果限制为 1–6。
- `density_profile=dense_cornell_v1`：≤10 个完整模块默认单页；多页目标每页 6–10 个问题—笔记对，若候选页低于 6 个模块就合并或减少页数
- `page_count=1` 时使用单页布局；`page_count>1` 时锁定同一视觉底座，按完整知识单元拆页，不把段落机械截断。
- 每页 Prompt 必须写 `series_id`、`page_number`、`page_count`、`page_label`；`page_label` 使用两位数格式 `NN/TT`，并作为左上角逐字文本。
- 每页都要有本页可回答的线索问题和笔记模块；最后一页放全文总结与一句话记忆，不能用重复内容填充。
- `density_audit` 必须写入 Prompt 与 manifest；若参考图被指定为 `style_density_reference`，跨页只改变主题事实、页码和本页示意图。
- manifest 使用 `series.page_count`、`series.page_marker: top_left` 和 `series.pages[]` 记录逐页 Prompt、图片和验收状态。

Text accuracy:
- 所有中文按上方内容逐字渲染，不得改写标题、问题、数字或专有名词
- 不添加随机英文、无关标签、Logo 或水印；页码仅允许使用已声明的 `NN/TT`
- 若内容过多，优先按知识单元拆成 2–6 页；每页保持 25%/75% 康奈尔布局，不把左右两栏堆成上下结构
- 如果生成结果只有 3–4 个大模块、标题占据主要画面或信息密度明显低于参考母版，判定为失败并重生，不得以“版式正确”通过

Final effect:
像一本大学教材中的高质量学习总结页，也像高播放课程的知识复习讲义；单页或系列页都一眼能看出康奈尔笔记结构，信息丰富但清楚、可扫描、可打印。
```

## 填充规则

1. 先建立“线索问题 → 右侧模块”的覆盖表；有问题没有答案时，先修内容，不进入生图。
2. 问题与模块数量随文章长度调整，但不得为了填满画面捏造原文内容。
3. 参考图只约束版式、手绘质感和密度；不得复制其中的 HTTP、内网穿透等示例内容。
4. 图片中的一句话记忆必须与 Prompt 落盘文件完全一致。
