# Prompt template: Editorial research minimal

## 定位

“研究编辑极简风（Editorial Research Minimal）”是一个可复用的文章封面/小结卡视觉系统：用大面积留白、清晰的标题阶梯、低饱和主题色、抽象线稿或局部破框主体，承载一个明确的研究命题。它抽象可观察的版式与材质规则，不复制任何品牌、设计师或第三方账号的商标、字体标志和原始提示词。

适用：`image_type: cover | summary_card`，默认 3:2；也可按平台切换到 4:5 或 16:9。文字密度为低到中，事实和标题仍需逐字核验。

## Prompt 分层

每次生成都把 Prompt 拆成四层，避免“万能模板”变成没有主题的空壳：

1. **基础视觉系统（base visual system）**：固定阅读顺序、字体角色、留白比例、网格、材质、阴影与颜色角色。系列内保持一致。
2. **主题佐料（topic seasoning）**：从文章事实提取一个主体、一个抽象关系和一组主题色；只改变与本主题有关的视觉变量。
3. **系列变量矩阵（variant matrix）**：候选版本最多改变 2–4 个轴，例如构图方向、裁切位置、色彩角色、隐喻物件或小型信息标记；保留系列识别度。
4. **事实与逐字文字（facts and exact text）**：标题、眉题、副标题、日期、数字和 CTA 单独列出；没有来源的数字、品牌断言和效果承诺不得进入图片。

## 最终 Prompt 母本

### source_grounding

- 来源：`【source】`；只使用 `【article_facts】` 中明确出现的命题、对象、数字和术语。
- 主命题：`【core_claim】`；视觉隐喻：`【metaphor】`。
- 不把缺失事实补成结论，不生成未经来源支持的品牌关系、版本、数据或用户评价。

### primary_task

设计一张可以在手机缩略图中先读懂标题和主题、打开后感到克制而有层次的文章 `【cover_or_summary】`。画面只服务一个主命题，不堆叠无关物件，不做通用科技海报。

### composition_and_layout

- 画布 `【aspect】`，采用编辑式模块网格；上方为眉题/来源标记，中部为 1–2 行主标题，下方为短副标题或一组小型信息标记。
- 保留约 45%–65% 的可呼吸留白；主体可从左/右/下边缘局部破框或悬浮，但不得遮住标题与关键文字。
- 主标题是第一阅读层，抽象主体是第二阅读层，注释、日期、关键词是第三阅读层；所有信息按明确阅读顺序对齐。
- 允许一条细线、括号、编号、坐标、手写式短标记或小色块作为引导，不把它们扩写成无关正文。

### visual_style_and_materials

- 平面编辑海报与轻量图形摄影/线稿复合，不使用网页截图、PPT 模板或厚重 3D 素材堆。
- 背景使用主题派生的低饱和色：暖灰、陶土橙、鼠尾草绿、深墨黑或同等克制色；用 1 个强调色承担视觉焦点，颜色按角色使用而不是随机换色。
- 标题使用高对比衬线或干净无衬线的字体角色；正文/标记更小、更轻，但必须保持清晰可读。禁止伪造品牌专用字体、Logo 或商标。
- 材质可有轻微纸张颗粒、印刷不均、柔和自然阴影和透明低饱和色块；边缘干净，避免过度发光、霓虹渐变和装饰噪声。

### exact_text

- 眉题：`【eyebrow】`
- 主标题：`【title】`
- 副标题：`【subtitle】`
- 小标记/日期/关键词：`【micro_labels】`
- 所有文字、标点、数字、英文专名逐字渲染；文字不足时减少小标记，不缩小主标题。

### aspect_and_output

- 目标比例：`【aspect】`；用途：`【purpose】`；输出 PNG 或 JPG，记录真实像素尺寸。
- 若做系列候选，使用同一基础视觉系统和字体阶梯，输出 `v1/v2` 版本而不是覆盖旧文件。

### constraints_and_avoid

- 不复制 Anthropic、其他公司或第三方账号的品牌识别、Logo、专用字体、原图或原提示词；只使用上述可观察视觉属性。
- 不生成伪二维码、随机英文、伪数据、软件界面、未提供的产品能力或无法回指来源的“效果证明”。
- 不把留白理解成信息不足：每个文字或视觉区域必须承担标题、主题、关系、证据提示或行动引导中的一种功能。
- 避免居中堆满、无层级卡片、过度饱和、长段落小字、主体遮挡文字、模糊中文和不可读的边缘裁切。

## 验收

先看缩略图是否能读到主标题与主题，再按 `exact_text` 逐字核对；确认基础视觉系统一致、主题佐料确实来自文章、留白没有删掉必要信息，并用 `view_image` 检查实际位图。
