# Aesthetic system: Brand system

## Compile fields

- `primary_color`
- `secondary_color`
- `neutral_background`
- `dark_background`
- `monochrome_color`
- `surface_and_contrast_rule`

## Rules

- 颜色按角色固定：主色负责识别，辅助色负责强调，黑白版本负责通用性。
- 渐变只能作为批准的品牌效果，不能用来掩盖几何和字标不稳定。
- 需要透明背景、浅底和深底三种使用场景时分别验收对比度。
- 不把“科技感、优雅、高级”直接当成可执行规则，必须落到色值、比例和对比关系。
