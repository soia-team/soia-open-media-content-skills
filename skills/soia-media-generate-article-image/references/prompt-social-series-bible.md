# Prompt deck: social skill series bible

这是 `repository_feature_pair` 的共享视觉底座，不是某一张图的完整成品 Prompt。每次交付复制到 `prompts/00-series-bible.md`，再由两张正式卡分别展开自己的完整 Prompt。

## base_visual_system

- 画布：4:5 竖版，安全区覆盖四周 6%；缩略图先读品牌/结果钩子，再读事实结构，最后读 CTA。
- 颜色角色：深蓝负责品牌与正文，白色负责信息面板，橙色只负责数字、重点和行动，最多增加一种来自仓库主题的辅助色。
- 字体角色：英文仓库名用清晰无衬线粗体；中文主标题用粗黑体或同等高对比字体；说明文字只保留短句，不能靠缩小塞内容。
- 版式：顶部品牌条 → 结果/痛点钩子 → 事实规模与能力结构 → 重点技能 → 输入/工作流/交付/验收 → CTA。
- 材质：轻量 3D 或图形插画、玻璃/纸张/金属的统一语言、柔和阴影与干净边缘；不做网页截图，不堆无关装饰。
- 组件：圆角面板、编号徽章、勾选图标、步骤箭头和 CTA 横栏在系列内保持同一比例与间距。

## density_and_readability

- 每个区块只承担一种新判断信息；删除后不影响判断的区块视为装饰。
- 单页最多 4–6 个能力组；详细输入、工作流和验收放到第二页，不把全部技能名缩成小字。
- 主标题、数量、重点技能名、安装命令、项目 URL 和二维码是高风险字段，必须逐字核验；二维码只接受真实 URL 编码。
- 保留真实截图/产物的原始文字，不用生图伪造证据；没有证据时标注“结构示意”或“产物形态示意”。

## series_variants

每个候选只改变 2–4 个轴：主视觉隐喻、构图方向、局部强调色、能力网格、截图位置或裁切方式。系列识别度、字体阶梯、CTA 位置和阅读顺序不变。

## avoid

不要复制第三方品牌 Logo、专用字体、原图或逐字提示词；不要添加未经 `facts.yml` / `content-facts.yml` 支持的数字、版本、测试结果、客户评价或功能。
