# Prompt template: Plugin / app icon

## 适用场景

- `image_type: icon`
- 插件市场图标、应用图标、技能库标识
- 同一批次多个图标需要保持可辨识的家族感

与其他模板的根本差异：**图标不承载文字**。其他模板靠逐字文字传达信息，图标只靠
一个字形（glyph）和统一的版式语言。因此本模板的 `text_density` 为 `none`，
`exact_text` 块必须显式声明「无文字」，验收时任何文字都判失败。

## 家族一致性契约

同一批次的多个图标必须共享以下参数，逐张 Prompt 里原样重复，不得各自发挥：

| 参数 | 约束 |
|---|---|
| 画布 | 1:1，1024×1024 |
| 底色 | 单一品牌色平涂，全批次同一 hex |
| 字形颜色 | 纯白 `#FFFFFF` |
| 字形占比 | 居中，占画布 52%–58%，全批次一致 |
| 描边 | 统一线宽的几何描边风格，无渐变、无高光、无阴影 |
| 圆角 | 由宿主裁切，画布本身画满，不自带圆角或外框 |
| 留白 | 四周等距，字形不触边 |

差异**只允许**出现在字形本身。若某张图的底色、字形占比或线宽与批次不符，
按质量门判失败并重生成，不得手工后期调整。

## 最终 Prompt 母本

```text
Use case: productivity-visual
Asset type: flat vector plugin icon

Primary request:
生成一张 1:1 的扁平矢量风格插件图标。画面主体是【字形描述】，居中构图，
除该字形外不出现任何其他元素。

Style:
- 扁平矢量，几何化，线条硬朗且线宽统一
- 背景为单一品牌色 【品牌色 hex】 平涂，无渐变、无噪点、无质感
- 字形为纯白 #FFFFFF，实心或统一线宽描边，二者不混用
- 无阴影、无高光、无立体、无拟物、无 3D 渲染
- 观感接近现代操作系统的系统图标，而非插画或 Logo 设计稿

Composition:
- 正方形画布 1024×1024
- 字形居中，占画布 【字形占比】，四周留白等距，不触边
- 画布画满品牌色，不自带圆角、外框、投影或底座
- 缩到 32×32 时字形轮廓仍可辨认

Text accuracy:
- 图上不得出现任何文字、字母、数字、水印或 Logo 文字
- 若字形本身是符号（如 </>），该符号不算文字，但不得附加说明文字

Avoid:
渐变、光晕、投影、立体感、拟物材质、多色配色、写实摄影、卡通人物、
文字标签、水印、外框、圆角卡片、多个并列元素、复杂细节。
```

## 字形选取原则

- 一个概念一个字形，不叠加两个隐喻
- 优先选已有约定俗成的符号（尖括号=代码、学士帽=课程、齿轮=环境）
- 避免需要文化背景才能读懂的符号
- 避免细节多到 32×32 会糊掉的字形（如密集的书架、多层建筑）

## 验收补充

除 [quality-gates.md](quality-gates.md) 的通用门外，图标批次额外检查：

1. `view_image` 逐张确认**无任何文字**
2. 并排比对全批次：底色一致、字形占比一致、线宽一致
3. 缩略到 32×32 复查轮廓是否仍可辨认
4. 任一张不符即重生成该张，不做后期修图
