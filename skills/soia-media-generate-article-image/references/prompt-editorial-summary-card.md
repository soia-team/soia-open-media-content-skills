# Prompt template: Editorial summary card

## 适用场景

- `image_type: summary_card`
- 公众号正文段落小结、观点摘录、章节收束

## 最终 Prompt 母本

```text
Use case: productivity-visual
Asset type: editorial article summary card

Primary request:
根据【文章段落】生成一张编辑式正文小结卡。画面只表达一个主命题，不解释整篇文章，不使用插画故事。主标题逐字写“【主命题】”，补充解释逐字写“【补充解释】”，来源逐字写“【来源】”。

Style:
- 高级杂志编辑设计，克制、理性、专业，不像商业 PPT
- 深海军蓝或依据文章选择的纯色/轻微质感背景
- 大号粗体中文主标题，清晰字级与宽松行距
- 1–3 个关键词用高对比强调色放大、改色或轻微错位
- 引号、细线、小型几何符号只承担节奏，不抢主标题
- 充足留白，边距统一，移动端缩略图仍能读懂主命题
- 若输入含 `reference_images[].role=style_density_reference`，沿用参考图的高密度模块栅格、顶部栏、双栏比例、字号层级和底部总结区；只替换本图事实，不从单一标题卡重新设计。

Composition:
- 按【目标比例】重新排版；默认 4:5 竖版
- 上方保留小型品牌/栏目位置，但客户未提供时保持空白，不生成 Logo
- 中部为主标题和关键词；下部为 2–4 行补充解释；底部为来源
- 文字是视觉主体，但不能像把一段 Markdown 直接贴在背景上
- 参考图为高密度学习母版时，补充 6–10 个源有依据的知识模块或问题—答案对，不得只保留 1–3 个大卡片；来源不足才减少模块。

Text accuracy:
- 只允许出现【主命题】【补充解释】【来源】三组客户提供的文字
- 逐字正确，不添加随机英文、额外口号、Logo 或水印

Avoid:
信息图网格、复杂图表、多段长文、卡通人物、摄影背景、霓虹科技 HUD、PPT 模板感、错误中文。
```
