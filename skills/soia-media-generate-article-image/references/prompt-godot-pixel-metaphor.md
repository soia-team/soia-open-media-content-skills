# Prompt template: Godot pixel metaphor

## 适用场景

- `image_type: cover | poster`
- 文章有明确观点、冲突、选择、循环困境、长期积累或人与系统的尺度关系

## 最终 Prompt 母本

```text
Use case: stylized-concept
Asset type: article cover or poster

Primary request:
把【文章主题】转化为一个可以被玩家体验的 Godot 2D 像素游戏世界。不要简单把标题画出来；只选择一个最强视觉隐喻，用角色、动作、空间关系、目标或阻碍表达文章的核心观点。

Internal selection:
内部构思多个方案，最终只选最容易理解、最有视觉冲击、最适合单张海报、情绪反差最强的一种。不要展示分析过程，不要混入第二个主要隐喻。

Required scene grammar:
- 一个主要角色
- 一个明确动作
- 一个核心象征物
- 一个目标或阻碍
- 一个视觉焦点
- 一块合理的标题留白

Metaphor candidates:
- 方向冲突：反向道路、传送带、消失终点
- 距离隐喻：远处城堡、山顶、出口、长桥
- 尺度反差：小人物面对巨塔、机器、城市或系统
- 循环困境：闭环地图、无限楼梯、重复房间
- 光暗选择：黑暗空间中的出口、火焰或森林入口
- 建造积累：城堡、图书馆、基地与持续升级
- 信息注意力：数据洪流、通知怪物与安静隐藏区

Style:
- 真正手工绘制感的 16-bit / 32-bit 像素艺术，不是普通图片套像素滤镜
- 统一 Sprite 尺度、Tilemap 环境、清晰像素边缘、游戏关卡设计感
- 电影级像素光影、环境叙事、精致细节
- 像真实存在的独立游戏宣传封面，不是游戏 UI，不是截图，不是概念草图

Composition:
- 按【目标比例】重新设计，不做简单裁剪
- 横版强调左右距离；竖版强调上下路径；正方形强调中心符号
- 主标题使用原文逐字标题“【文章标题】”，以像素字体融入建筑、道路、光影或场景符号
- 只强化 1–3 个关键词；中文必须清晰可读

Color and mood:
依据文章情绪从明亮冒险、暗黑幻想、科技未来、温暖成长中选一套，不固定配色。

Avoid:
写实摄影、3D 渲染、普通动漫、矢量插画、PPT、信息图、四宫格、多主角、游戏 UI、大量文字、随机英文、Logo、水印、模糊像素、错误中文、不统一像素比例。
```
