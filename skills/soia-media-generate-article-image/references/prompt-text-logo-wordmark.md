# Text strategy: Logo wordmark

## Compile fields

- `verbatim_wordmark`
- `case_and_language`
- `approved_font_or_path`
- `tracking_and_baseline`
- `tagline_policy`
- `outline_requirement`

## Rules

- 字标必须逐字来自客户输入或批准资产；不得由模型随机生成。
- 阶段 1 可用占位字标位置探索构图；阶段 2 必须使用批准字体或字形路径。
- 记录大小写、字距、基线、中文字体 fallback 和最小可读尺寸。
- 副标题不是 Logo 必备组件；没有明确输入时不自行添加。

## Acceptance

- 字标拼写和大小写完全匹配。
- SVG 终稿不能依赖未安装字体；生产交付优先转为路径。
